# Política de segurança

Não publique credenciais, tokens, cookies, documentos privados, queries estratégicas, memória de investigação ou dados que não estejam autorizados para redistribuição em issues, pull requests ou commits.

Se você encontrar uma possível exposição sensível, não a reproduza publicamente. Entre em contato de forma privada com o mantenedor do repositório para que o artefato possa ser removido, preservado em ambiente seguro e analisado sem ampliar a exposição.

A política de dados em `docs/DATA_POLICY.md` explica por que o repositório publica evidência e proveniência selecionadas, mas mantém o laboratório operacional separado.
